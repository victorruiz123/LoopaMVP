# Loopa — loopa.nu

Production site for Loopa ("AI for secondhand"), built with Vite + React +
TypeScript + Tailwind CSS v4. Single-page marketing site with a bilingual
(SV/EN) UI, an interactive product-listing demo, an "Ask Loopa" chat backed
by a Cloudflare Pages Function proxying Gemini, and a simulated buy/delivery
flow.

## Develop

```bash
npm install
npm run dev
```

The `/api/chat` endpoint used by the Ask Loopa chat is a Cloudflare Pages
Function (`functions/api/chat.ts`) and is not served by plain `vite dev`. In
local dev without `wrangler pages dev`, the chat widget automatically falls
back to deterministic local-demo answers (clearly labeled in the UI) so the
flow stays testable end to end.

To run the Function locally as well:

```bash
npm run build
npx wrangler pages dev dist
```

## Build

```bash
npm run build   # tsc -b && vite build -> dist/
npm run preview # preview the production build locally
```

## Environment variables (Gemini chat)

Copy `.env.example` and configure as Cloudflare Pages environment
variables/secrets (Pages project → Settings → Environment variables) —
never commit real values.

- `GEMINI_API_KEY` — Google AI Studio key. If unset, `/api/chat` returns
  deterministic local-demo answers instead of failing.
- `GEMINI_MODEL` — defaults to a cheap Gemini Flash-Lite class model.
- `AI_GATEWAY_URL` — optional, routes Gemini calls through a Cloudflare AI
  Gateway instead of calling Google directly.

The fixed-price / no-negotiation rule for the demo listing is enforced
deterministically in `src/lib/listingQA.ts` (before and after the model
call), not just via the system prompt.

## Source assets

`Design Pictures/`, `Person Pictures/`, `Listing Pictures/` and
`IKEA SÖDERHAMN/` are the original, read-only source assets. Optimized
copies used by the site live in `public/assets/`, generated by
`scripts/optimize-images.mjs` (re-run it if the source photos change).

### Fashion demo photography

The "Generate with Loopa" / fashion recommerce walkthrough uses real product
photography of **Asket "The Overshirt", Dark Navy**
(https://www.asket.com/en-us/mens-overshirt-dark-navy), downloaded once via
`scripts/fetch-fashion-demo-assets.mjs` (a one-time dev step, not a runtime
scraper — no hotlinking, images are optimized and served from
`public/assets/fashion-demo/`). Real facts reused in the demo copy: the
product name ("Overshirt"), colour ("Dark Navy" / "Marinblå"), and material
("100% organic cotton, sturdy double twill"). Loopa has no affiliation with
Asket; the photos stand in as realistic garment photography for the
illustrative demo, not as an endorsement or integration claim.

## Deploy (Cloudflare Pages)

1. Push this repo to GitHub/GitLab and connect it as a Cloudflare Pages
   project (or `npx wrangler pages deploy dist` after `npm run build`).
2. Build command: `npm run build`, output directory: `dist`.
3. Set the environment variables above in the Pages project settings.
4. Connect the `loopa.nu` custom domain once ready (DNS not configured by
   this repo).
