# det första forward-passet).

# dubblett: type_system/grouping.py:80 importerar yaml utan try/except, och vocab()
# ligger på inläsningsvägen via assign_cells. Lokalt råkar det fungera för att
# ultralytics drar in PyYAML transitivt — tas torch-paketen bort utan den här raden
# dör motorn vid uppstart med ModuleNotFoundError.
